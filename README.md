# Нейропомощник

Учебное одностраничное веб-приложение для методолога: помогает превратить задачу в понятный и готовый результат. Фронтенд собран на Vite и обычном JavaScript, сервер — на Node.js и Express. Ответы генерирует модель OpenAI.

## Что умеет приложение

- Составлять план дня.
- Создавать чек-листы.
- Готовить текстовые шаблоны.
- Предлагать идеи для обучения и работы.
- Обрабатывать свободный запрос как практичный деловой помощник.

## Требования

- Установленный [Node.js](https://nodejs.org/) (с npm).
- Ключ OpenAI API.

Docker, WSL, Python и база данных не нужны.

## Установка зависимостей

В папке проекта выполните:

```bash
npm install
```

## Как заполнить .env

1. Откройте файл `.env` в корне проекта.
2. Вставьте свой ключ OpenAI в строку `OPENAI_API_KEY=` без пробелов и кавычек.
3. При необходимости оставьте модель `gpt-4o-mini` или укажите другую в `OPENAI_MODEL`.
4. Порт сервера по умолчанию: `3001`.

Пример безопасного шаблона есть в файле `.env.example`. Настоящий ключ туда не копируйте.

## Как запустить в Dev-режиме

```bash
npm run dev
```

Откройте в браузере адрес Vite, обычно:

`http://localhost:5173`

В режиме разработки запросы `/api` проксируются на Express.

## Как собрать проект

```bash
npm run build
```

Сборка появится в папке `dist`.

## Как запустить собранную версию

Сначала выполните сборку, затем:

```bash
npm start
```

Откройте в браузере:

`http://127.0.0.1:3001`

Express отдаёт собранный фронтенд из папки `dist` и обрабатывает `/api/assist`.

## Как пользоваться приложением

1. Выберите режим: «План дня», «Чек-лист», «Текстовый шаблон», «Идеи» или «Свободный запрос».
2. Введите задачу в большое поле. Под полем показан пример для выбранного режима.
3. Нажмите «Отправить».
4. Дождитесь сообщения «Готовлю ответ…».
5. Скопируйте результат кнопкой «Скопировать результат» или очистите форму кнопкой «Очистить».

## Структура проекта

- `index.html` — разметка страницы.
- `src/main.js` — логика интерфейса и запрос к API.
- `src/style.css` — стили.
- `server.js` — Express-сервер и обращение к OpenAI.
- `vite.config.js` — настройки Vite и прокси `/api`.
- `.env` — локальные секреты и настройки (не публиковать).
- `.env.example` — безопасный пример переменных окружения.
- `package.json` — зависимости и команды.

## Важно

Файл `.env` и настоящий API-ключ публиковать нельзя. Не отправляйте ключ в чат, не кладите его во фронтенд и не добавляйте `.env` в репозиторий. Ключ читает только сервер.
